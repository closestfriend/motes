# Motes Custom UI — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Motes' generic editor with a bespoke, audio-reactive UI — a bioluminescent particle field (a true visual readout of the granular engine) plus custom-drawn knobs for all 13 params.

**Architecture:** Add two lock-free meters to the C engine (output RMS + a monotonic grain-fired counter) read on the GUI thread. A new `MotesField` JUCE component runs a 60 Hz particle simulation driven by those meters + params. A `MotesLookAndFeel` draws the knobs. `MotesEditor` composes field + knobs at a fixed 768×512.

**Tech Stack:** C11 (core, `<stdatomic.h>`), C++17 + JUCE 7 (plugin), CMake + Unix Makefiles, `auval`.

## Global Constraints

- **Platform:** macOS Apple Silicon arm64 native. Build generator **Unix Makefiles** (`cmake -B build -G "Unix Makefiles" -DCMAKE_BUILD_TYPE=Release`) — NOT Xcode.
- **Language split:** `src/core/` = pure C11 (no JUCE/C++); `src/plugin/` = C++17.
- **RT-safety:** the audio-thread path (`ge_render`→`voice_render`) does NO malloc/free/locks. New meters are **relaxed atomics only**.
- **AU id:** `aumu Mote Hntr`. Build targets: `Motes_AU`, `Motes_VST3`. Core test target: `test_core` (has `-UNDEBUG` so `assert()` stays live under Release).
- **Window:** fixed **768×512** (not resizable in v1).
- **No asset dependency:** background is a procedural gradient; a future embedded plate is optional and must not be required by any code path.
- **Palette:** bg near-black `#0A0D12` → deep indigo `#0E1420`; mote core `#EAF6FF`; glow cyan `#34C7DE` + violet `#A07CFF`; label `#7C8AA0`, value `#C6D4E6`.
- **Git:** personal `origin` only; NEVER Memetica. Commit trailer: `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.

```c
void ge_render(GranularEngine* e, float* l, float* r, int n){
    for(int i=0;i<n;i++){ l[i]=0.f; r[i]=0.f; }
    unsigned fired=0;
    if(e->has_sample){
        for(int i=0;i<e->max_voices;i++) if(e->voices[i].active)
            fired += (unsigned)voice_render(&e->voices[i],&e->sample,&e->params,e->sr,l,r,n,&e->rng);
    }
    if(fired) atomic_fetch_add_explicit(&e->grains_fired, fired, memory_order_relaxed);
    double sumsq=0.0;
    for(int i=0;i<n;i++){ sumsq += (double)l[i]*l[i] + (double)r[i]*r[i]; }
    float rms = (n>0) ? (float)sqrt(sumsq/(2.0*n)) : 0.0f;
    atomic_store_explicit(&e->out_rms, rms, memory_order_relaxed);
}
```

- [ ] **Step 3: Write `MotesField.cpp` (ambient only)**

```cpp
#include "MotesField.h"

MotesField::MotesField(MotesProcessor& p) : proc(p) { startTimerHz(60); }

void MotesField::spawnAmbient(int n) {
    for (int i=0;i<n;i++) {
        Mote& m = motes[cursor]; cursor = (cursor+1) % MAX_MOTES;
        m.active = true;
        m.x = rng.nextFloat() * (float)getWidth();
        m.y = (float)getHeight() * (0.4f + 0.6f*rng.nextFloat());
        m.vx = (rng.nextFloat()-0.5f) * 6.0f;
        m.vy = -(4.0f + rng.nextFloat()*10.0f);          // slow upward buoyancy
        m.age = 0.0f; m.life = 2.0f + rng.nextFloat()*3.0f;
        m.size = 1.5f + rng.nextFloat()*2.0f;
        m.hue = rng.nextFloat();                          // 0=cyan .. 1=violet
    }
}

void MotesField::timerCallback() {
    const float dt = 1.0f/60.0f;
    float rms = proc.getOutRms();
    // ambient spawn rate scales with loudness (gentle)
    float rate = juce::jlimit(0.0f, 12.0f, rms * 60.0f);
    int n = (int)rate + ((rng.nextFloat() < (rate - (int)rate)) ? 1 : 0);
    spawnAmbient(n);
    for (auto& m : motes) {
        if (!m.active) continue;
        m.age += dt;
        if (m.age >= m.life) { m.active = false; continue; }
        m.x += m.vx*dt; m.y += m.vy*dt;
        m.vx += (rng.nextFloat()-0.5f) * 4.0f * dt;       // subtle drift noise
    }
    repaint();
}

void MotesField::paint(juce::Graphics& g) {
    juce::ColourGradient bg(juce::Colour(0xff0a0d12), 0, 0,
                            juce::Colour(0xff0e1420), 0, (float)getHeight(), false);
    g.setGradientFill(bg); g.fillAll();
    juce::Colour cyan(0xff34c7de), violet(0xffa07cff);
    for (auto& m : motes) {
        if (!m.active) continue;
        float t = m.age / m.life;
        float alpha = juce::jlimit(0.0f, 1.0f, std::sin(t * juce::MathConstants<float>::pi)); // fade in/out
        auto col = cyan.interpolatedWith(violet, m.hue).withAlpha(alpha * 0.5f);
        float r = m.size * (1.0f + t*0.5f);
        g.setColour(col);
        g.fillEllipse(m.x-r, m.y-r, r*2, r*2);            // soft dot
    }
}
```

```cpp
void MotesField::spawnBloom(int n, float gx) {
    float spread   = proc.apvts.getRawParameterValue("spread")->load();
    float panSpread= proc.apvts.getRawParameterValue("panspread")->load();
    for (int i=0;i<n;i++) {
        Mote& m = motes[cursor]; cursor = (cursor+1) % MAX_MOTES;
        m.active = true;
        float jitter = (rng.nextFloat()-0.5f) * (0.15f + panSpread*0.85f) * (float)getWidth();
        m.x = juce::jlimit(0.0f, (float)getWidth(), gx*(float)getWidth() + jitter);
        m.y = (float)getHeight() * (0.55f + 0.4f*rng.nextFloat());
        m.vx = (rng.nextFloat()-0.5f) * (10.0f + spread*40.0f);
        m.vy = -(12.0f + rng.nextFloat()*22.0f);          // blooms rise faster
        m.age = 0.0f; m.life = 0.5f + rng.nextFloat()*0.9f;  // short, punchy
        m.size = 2.5f + rng.nextFloat()*3.5f;              // bigger/brighter
        m.hue = rng.nextFloat();
    }
}
```
